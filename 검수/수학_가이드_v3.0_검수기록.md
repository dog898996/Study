# 수학 출제 가이드 v3.0 검수 기록

검수일: 2026-11-03
대상: `수능_수학_문제출제_가이드라인.md`
기존 버전: v2.1, blob `4d2affe934d6f9641f9567cb8c269ff543a4720f`
검수 주체: 현재 대화의 AI 1개. 별도 사람·다른 모델·하위 에이전트의 독립 검수는 실시하지 않았다.

## 1. 결론

v2.1은 수학적 오류를 줄이기 위한 원칙으로는 유용하지만, 그 문서만 주면 평가원에 가까운 고난도 문항을 안정적으로 생성할 수 있다고 판정할 근거는 부족했다. 입력 사양, 기출 준거, 체크 항목별 증거, 난도 판정, 학생용 출력 계약이 약했다.

v3.0은 이러한 누락을 보완한 실행 가능한 출제·검수 지침이다. 가이드의 논리와 적용 가능성을 검토한 것이며, 실제 평가원 문항 수준이나 학습자 정답률을 인증한 것은 아니다. 여러 문항을 생성하는 독립 모델 실험과 실제 응시자 평가도 아직 하지 않았다.

## 4. 결함·정상 사례 적용 시험

아래는 가이드가 잘못된 문항을 거부하면서 정상 문항을 과도하게 금지하지 않는지 확인한 수동 논리 시험이다. AI의 자동 생성 성능이나 통계적인 오류 검출률을 측정한 실험은 아니다.

| 사례 | 검사 대상 | 실제 수학적 근거 | 판정 |
|---|---|---|---|
| A | 실수 x에 대해 x²=1만 주고 x를 하나로 요구 | x=1과 x=-1이 모두 성립 | 답 비유일, 수정 필요 |
| B | x²=1만 주고 x²를 요구 | 두 가능한 x에서 요구한 값은 모두 1 | 정상. 대상 비유일만으로 기각 금지 |
| C | x=1과 x=2를 동시에 요구 | 한 실수 x가 두 값을 동시에 가질 수 없음 | 존재성 실패 |
| D | √(x+2)=x-4를 제곱하고 후보를 모두 채택 | 제곱식의 후보 2와 7 중 2는 원식에서 2=-2가 되어 탈락 | 무연근 검사 필요 |
| E | 모든 실수 a에 대해 ax=a의 해를 x=1로 단정 | a=0이면 모든 실수 x가 해 | 매개변수 0 분기 누락 |
| F | 0<x<1에서 x의 최댓값을 1로 제시 | 1은 범위 밖이며, 임의의 x에 대해 (x+1)/2가 더 큰 허용값 | 최댓값 미존재 |
| G | 정답이 √8인 선택형에 2√2도 별도 선지로 포함 | 두 표현이 같은 양수 | 정답 선지 중복 |
| H | x²=1의 해의 합을 구하는 문제를 고난도 실전 문항으로 제시 | 기본 해 결정만으로 해결됨 | 성립하지만 고난도 근거 부족 |

B는 중요한 정상 통과 사례다. 검수 기준을 엄격하게 만든다는 이유로 함수나 매개변수가 반드시 하나로 결정되어야 한다는 불필요한 조건을 추가하지 않는다.

## 5. 실제 시험 제작 1문항 — 검수용, 학생에게 출제한 회차 아님

### 문항

양수 a에 대하여 방정식

log₂((x-2)²) = log₂(ax)

의 서로 다른 두 실근을 r, s (r<s)라 하자. s-r=3일 때, a의 값을 구하시오.

이 문항은 범위·정의역·존재·유일성·난도 분리 검사의 작동을 확인하기 위해 새로 작성했다. 고난도 실전 문항으로 채택하지 않는다.

### 범위와 풀이

사용 도구는 로그의 정의 및 일대일 성질, 이차방정식, 근과 계수의 관계다. 지수·로그함수 미분이나 수치해석은 필요 없다.

a>0이므로 원식의 정의역은 x>0, x≠2다. 정의역 안에서 원식은

(x-2)²=ax, 즉 x²-(a+4)x+4=0

과 동치다. 판별식은 a²+8a>0이므로 서로 다른 두 실근이 있다. 두 근의 합 a+4가 양수이고 곱은 4이므로 두 근 모두 양수다. x=2를 대입하면 -2a≠0이므로 어느 근도 2가 아니다. 따라서 이 이차방정식의 두 근이 모두 원식의 유효한 해다.

(s-r)²=(r+s)²-4rs=(a+4)²-16=a²+8a.

s-r=3에서 a²+8a=9, 즉 (a-1)(a+9)=0이다. a>0이므로 a=1만 남는다. 이때 이차식은 (x-1)(x-4)로 인수분해되고, 1과 4를 원래 로그식에 대입해 각각 성립하며 차는 3이다. 존재성과 요구한 값의 유일성이 모두 확인된다.

### 발상·재검증·난도

- 발상 근거: 같은 밑의 로그가 같다는 관계로 진수를 비교할 수 있고, 두 근의 차는 근의 합·곱과 연결할 수 있다.
- 재검증: a=1에서 원식의 두 해를 직접 확인하고, 음수 후보를 원조건으로 제외했다. 판별식 방식과 근의 합·곱 방식은 같은 대수 관계를 공유하므로 완전히 독립된 별해라고 과장하지 않는다.
- 난도 판정: 기본 개념 연결과 정의역 확인은 있으나 고난도에 필요한 탐색·조건 종합 부담은 부족하다. 수학적 검수는 통과, 고난도 요청에 대한 채택은 보류한다.
- 조건 변형 시험: 근의 차를 0으로 바꾸면 ‘서로 다른 두 실근’과 충돌하며, a>0에서 판별식도 항상 양수이므로 성립하지 않는다. 수치만 바꾼 문제도 재검증해야 함을 확인했다.

## 6. 계산 보조 확인과 한계

Python 표준 라이브러리로 위 사례 일부의 구체적인 수치 관계, 시험 문항의 후보·정의역·원식 대입·근의 차, 잘못 바꾼 조건의 후보를 확인하는 11개 단언을 실행했고 모두 통과했다. 이는 간단한 계산 보조이며, 11개 서로 다른 문항을 검증했다는 뜻은 아니다.

처음 시도한 SymPy 검산은 모듈이 설치되어 있지 않아 실행되지 않았다. 이후 표준 라이브러리로 가능한 계산만 확인했다. 존재성과 모든 경우에 대한 유일성은 위의 수학적 논증에 근거한다. 수치 코드가 일반 증명을 대신하지 않는다.

## 7. 남은 검증

- 실제 고난도 문항을 여러 단원에서 생성하고, 문항과 해설을 분리해 외부 검토하는 실험은 미실시.
- 실제 수험생의 풀이 시간·정답률·오개념 분포는 미측정.
- 기출 비교 범위는 제한적이다. 실제 출제마다 해당 단원·난도의 원문 준거를 다시 확보해야 한다.
- 가이드를 읽었다는 사실만으로 품질이 보장되지 않는다. 최종 문항마다 증거를 남기고, 결함이나 난도 미달이 있으면 다시 설계하는 절차까지 실행해야 한다.
